
# Clean Dataset – Data Analytics Project

## Project Overview

Clean Dataset is a web-based data cleaning application developed using Python, Flask, Pandas, HTML and CSS.

The application helps users upload CSV datasets, identify data quality issues, remove duplicate records, handle missing values and download cleaned datasets.

## Features

- CSV Dataset Upload
- Dataset Preview
- Remove Duplicate Records
- Handle Missing Values
- Remove Empty Rows
- Data Quality Report
- Data Cleaning Summary
- Download Cleaned CSV
- Responsive Dashboard UI

## Technologies Used

- Python
- Flask
- Pandas
- HTML5
- CSS3
- JavaScript

## Installation

1. Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

```bash
cd Clean_Dataset
```

3. Install dependencies.

```bash
pip install -r requirements.txt
```

4. Run the application.

```bash
python app.py
```

5. Open your browser.

```text
http://127.0.0.1:5000
```

## How It Works

1. Upload a CSV dataset.
2. Preview the uploaded records.
3. Select data cleaning operations.
4. Remove duplicate records.
5. Handle missing values.
6. View the data quality report.
7. Download the cleaned CSV file.
